# Dota 2 Build Quiz

Лёгкая браузерная игра: угадай героя Dota 2 по предметам из реального матча.

**Главное:** один Docker-контейнер; минимум нагрузки на хост; вся игра работает в браузере **без запросов во время партии**. Сервер только собирает, фильтрует и выдаёт задания до начала игры.

**Стек:** Python + FastAPI, HTML/CSS/Vanilla JS. Позже — SQLite.

### Фильтрация заданий (v0.1)

- Матч длится **более 30 минут** (`duration > 1800`).
- Берём сборки **только победивших игроков**.
- Заполнено **5 или 6 основных слотов** (не обязательно все 6).
- Один и тот же предмет встречается **не более двух раз**.
- ID героя и предметов корректны; нейтральный предмет учитывается отдельно.
- Повторные задания не сохраняем.

### Первый этап

1. Поднять Python/FastAPI и статическую веб-страницу в **одном контейнере**.
2. При первом запуске фоново получить список матчей и их сборки; отсеять некорректные и повторные записи.
3. Сохранить готовые задания в JSON на постоянном томе Docker. При повторном старте использовать их сразу, не ожидая OpenDota.
4. Показать статус «Сбор заданий», пока не подготовлено около **100 вопросов**; затем открыть кнопку «Играть». В фоне продолжать сбор до **5000** с учётом лимитов OpenDota.
5. До начала партии загрузить задания и изображения в браузер. Во время игры — **0 сетевых запросов**.
6. Проверить запуск одной командой, работу без сети и малое потребление RAM/CPU.

Без отдельного Nginx, PostgreSQL, Redis, очередей и лишних сервисов.
