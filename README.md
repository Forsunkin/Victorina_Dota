# Dota 2 Build Quiz

Браузерная викторина: угадай героя Dota 2 по предметам из реального матча.

**Идея:** браузер загружает вопросы и изображения заранее, затем играет без сетевых запросов. Минимум зависимостей и ресурсов; запуск в Docker на любом сервере.

## Стек

HTML, CSS, Vanilla JS; Python для обработки матчей. Позже — FastAPI и SQLite.

## Версии

| v0.2 | Интерфейс и кеширование для игры без сети |
