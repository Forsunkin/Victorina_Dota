# Dota 2 Build Quiz

Угадай героя Dota 2 по предметам из реального матча. Браузер заранее получает вопросы и изображения; во время игры сетевых запросов нет.

**Стек:** HTML, CSS, JavaScript, Python; позже — FastAPI и SQLite. Развёртывание в Docker.

## План

**v0.1 — первая рабочая версия:**
1. Разово получить ~5000 записей реальных матчей и отфильтровать их локально на Python.
2. Сформировать готовый `questions.json` и подготовить изображения.
3. Сделать простую страницу: показать сборку → выбрать героя → увидеть ответ → следующий вопрос.
4. Запустить в Docker и проверить игру без сетевых запросов.

Пока **без очков, жизней, рекордов, базы данных и API**. Набор вопросов заменяем вручную.
