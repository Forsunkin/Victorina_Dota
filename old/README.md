# Архив старой версии

Учебный прототип Dota 2 Build Quiz, написанный на Python в 2022 году.

Здесь сохранились ранние эксперименты со сбором данных о матчах через OpenDota и хранением сборок в SQLite. Код оставлен для истории развития проекта и не используется в актуальной версии.

Это архив, а не поддерживаемая версия приложения.
